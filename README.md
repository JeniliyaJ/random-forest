# Random Forest Machine Learning Project

This repository contains end-to-end Machine Learning implementations and exploratory data analysis using **Random Forest** and other supervised learning algorithms in Python.

---

## 📁 Repository Structure

* **`bike_sales.ipynb`** – Exploratory data analysis and predictive modeling on bike sales data[cite: 2].
* **`house_price_prediction.ipynb`** – Regression models to predict housing prices[cite: 2].
* **`passenger_prediction.ipynb`** – Classification and prediction modeling for passenger datasets[cite: 2].
* **`WA_Fn-UseC_-Telco-Customer-Churn.csv`** – Telco customer churn dataset[cite: 2].
* **`realistic_housing_data.xlsx`** – Housing dataset in Excel format for preprocessing and modeling[cite: 2].
